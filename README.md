# Anonify
Data anonimization platform that securely detects and masks sensitive information.
## Features
- Data anonymization
- Randomized fake data generation
- CSV/Excel file processing
- User-friendly GUI interface
- Secure handling of sensitive information

## Technologies Used
- Python
- Pandas
- CustomTkinter
- Faker

## Installation
```bash
pip install -r requirements.txt
```

## Run the Project

```bash
python main.py
```

## Project Structure

- `main.py` → Main application logic
- `requirements.txt` → Project dependencies
